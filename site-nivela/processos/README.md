# Processos

Esta pasta contém os prompts utilizados para produção de conteúdo da Nivela.

Objetivo:

- documentar os processos;
- facilitar revisões;
- manter histórico das alterações;
- evitar que o conhecimento fique apenas com quem executa.

## Fluxo

1. Gerar ideias de conteúdo.
2. Escrever o artigo.
3. Gerar a versão Feed.
4. Criar a arte.
5. Publicar.
