# Prompt 4 — Escrita de Feed Standalone (LinkedIn)

> Use quando quiser gerar um post de feed direto, sem passar pelo artigo antes. Cole depois do Prompt 1, na mesma conversa (não abra chat novo).

```
Use o contexto da empresa já definido acima. Agora escreva um POST DE FEED
de LinkedIn (não artigo) sobre a ideia [colar a ideia escolhida do Prompt 1].

FORMATO
- Até 150 palavras (900–1500 caracteres)
- Primeiras 2 linhas (~140 caracteres) funcionam como gancho antes do corte
  "ver mais" — nunca abrir com contexto morno, sempre com risco/decisão/dado
  contra-intuitivo
- Corpo em blocos curtos de 1-3 linhas, quebra de linha generosa (LinkedIn
  pune parágrafo denso)
- Fechamento com reframe ou pergunta genuína — nunca "concorda?" vazio
- CTA opcional de 1 linha (nem todo post de Autoridade/Institucional precisa)
- 3-5 hashtags no fim, mix de nicho técnico (#SIGEF #Georreferenciamento
  #Usucapião) e amplo (#RegularizaçãoFundiária #DireitoImobiliário)

REGRA DE VOZ
Zero institucionalês. Proibido: "qualidade", "excelência", "compromisso",
"soluções inovadoras". Trocar sempre por especificidade operacional real
(ART por vértice, rede geodésica rastreável, exatidão cartográfica
documentada) — se a frase poderia estar no post de qualquer concorrente,
ela morre.

PITCH DE AUTORIDADE (lastro, não copiar literalmente)
Pode citar normas técnicas relevantes (NBR 13.133, NTGIR, SIRGAS2000, ART)
quando reforçar o argumento, mas varie a construção da frase sempre — nunca
reutilize a mesma frase-lastro de outro post.

SAÍDA
Entregue o texto pronto para colar direto no LinkedIn, sem comentário
adicional antes ou depois.
```

---

**Nota de uso — não faz parte do prompt acima:**
Use este prompt só quando NÃO for gerar o artigo completo antes — se o plano é ter artigo + feed do mesmo gancho, use o Prompt 2, que já gera os dois na mesma conversa. Rodar os dois prompts pro mesmo tema em conversas separadas tende a gerar gancho duplicado com abordagem inconsistente entre si.
