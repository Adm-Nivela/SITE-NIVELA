# Prompt 8 — Imagem para Artigo do Site (hero/destaque + OG)

> Use depois que o artigo do site (Prompt 7) já estiver aprovado.

```
Gere o briefing de imagem para o artigo de site abaixo, seguindo o Brand
Book da Nivela.

TEXTO DE REFERÊNCIA: [colar o artigo do site já aprovado]

IDENTIDADE VISUAL (obrigatório respeitar)
- Azul Petróleo #0F3C57 — predominante, 60%
- Verde Ardósia #2F4F4F — apoio, 30%
- Dourado Fosco #CBB354 — máx. 10%, só em detalhe pontual (regra da
  escassez, nunca fundo/bloco de texto)
- Off-White #F4F5F6 — base neutra
- Tipografia: Lora (títulos), Avenir/Inter (texto)
- Estilo: minimalista, sofisticado, engenharia de alto padrão — aparência
  de revista especializada, não de banco de imagem corporativo

RESTRIÇÕES ESTRITAS
- NÃO usar fotos de pessoas (advogados, engenheiros, clientes)
- NÃO usar aperto de mão ou banco de imagens genérico
- NÃO usar clichê jurídico (martelo de juiz, balança da justiça, balcão de
  cartório)

ESPECIFICAÇÕES TÉCNICAS (site tem 2 saídas, não 1)
1. Imagem de destaque/hero do artigo: 1920x1080px, mesma lógica do padrão
   de capa de artigo já usado no LinkedIn — reaproveitar quando fizer
   sentido visual
2. Imagem OG (compartilhamento em redes/WhatsApp quando o link do artigo
   for compartilhado): 1200x630px, título do artigo legível em thumbnail
   pequeno, mesma paleta

CONCEITUAÇÃO
Traduzir o texto em metáfora visual abstrata ligada a linhas de topografia,
mapas vetoriais, estruturas geométricas sólidas ou sobreposição de camadas
de dados terrenos — nunca ilustração literal de "advogado lendo papel".

REGRA CRÍTICA DE COERÊNCIA
A imagem tem que representar exatamente o cenário do artigo de referência.
Nunca usar imagem de um contexto para ilustrar texto de outro.

SAÍDA
Para cada uma das 2 saídas (hero e OG): descrição da composição pronta pra
gerar ou selecionar banco de imagens, e o título exato sugerido pra escrever
na peça em Lora Bold.
```

---

**Nota de uso — não faz parte do prompt acima:**
A imagem hero (1920x1080) pode ser literalmente a mesma peça usada como capa quando o artigo também virar post de LinkedIn — não precisa gerar duas artes diferentes pro mesmo conteúdo, só adaptar o corte quando o formato exigir.
